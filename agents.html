智能体工作流

三个智能体串成一条研究流水线：找文献 → 避坑 → 汇报，上游产出自动成为下游输入。

1

论文分析 Agent

把论文拆成可复用的知识

自动解析论文结构（摘要层次 / 引言逻辑 / 创新点提取），关联前人批注，并生成「先问再推」的思考题，引导新生主动阅读而非被动浏览。

  • 论文结构拆解与创新点提取
  • 关联导师 / 学长的前人批注
  • 生成苏格拉底式思考题

避坑顾问 Agent

踩坑前先问一句

当学生描述实验 / 设计想法时，先从失败案例库匹配相似坑，再通过反问引导学生自己意识到风险，避免重复踩前人踩过的坑。

  • 匹配相似失败案例
  • 苏格拉底式反问问诊
  • 关联论文经验给出避坑建议

汇报生成 Agent

  • 聚合阅读 / 实验 / 失败记录
  • 生成结构化组会汇报草稿

单 Agent vs 多 Agent

为什么研脉用「多智能体 + 编排器」，而不是一个通用大模型包办所有环节。

单 Agent（通用大模型）

一个模型包办全部

  • 文献 / 避坑 / 汇报全都一个模型做
  • 上下文易膨胀，越聊越乱
  • 专业度不足，幻觉风险高
  • 出问题无法按环节追责

多 Agent（研脉）

分工 + 编排 + 共享知识库

  • 三个 Agent 各司其职、专业聚焦
  • Orchestrator 统一调度、上下文隔离
  • 共享知识库避免数据孤岛
  • 每步产出可回溯、可追责
